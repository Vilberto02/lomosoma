# QR de Yape

Coloca aquí el PNG real del titular como `yape.png` antes de habilitar pagos.
Configura `YAPE_QR_URL=/payments/yape.png` y `YAPE_RECIPIENT` en Render.
El archivo será público: utiliza únicamente el QR y los datos que el titular autorice publicar.
No coloques comprobantes, claves, documentos ni datos bancarios en esta carpeta.
